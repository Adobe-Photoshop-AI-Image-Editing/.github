# Adobe Photoshop: Photo Editing, Graphic Design and Digital Art

---

## What Is Adobe Photoshop?

Adobe Photoshop is an image editing application used for photo retouching, digital artwork, graphic design, image compositing, and visual content creation. It combines layer based editing, selection tools, masks, brushes, filters, and color adjustments in a single workspace.

The application gives users detailed control over individual image elements. Layers make it possible to combine text, photographs, shapes, and visual effects while keeping separate elements editable. Masks help control which parts of an image are visible, allowing detailed changes without permanently altering the original layer.

Photoshop also includes generative AI features for adding or removing objects, extending image boundaries, and creating visual variations. Generative Fill and Generative Expand combine text instructions with selected image areas to create edits that can be refined using familiar editing tools.

From portrait retouching and background replacement to digital painting and complex visual compositions, Adobe Photoshop serves a wide range of creative tasks. Its file handling and export settings also help prepare images for print, websites, presentations, and social media.

## Core Image Editing Features

### Layers and Masks

Layers let users combine separate visual elements in one document. Text, photographs, shapes, adjustments, and effects can each occupy their own layer, making complex compositions easier to organize.

Layer masks control which areas remain visible. They are useful for blending images, refining selections, changing backgrounds, and applying localized edits while retaining the original image data.

### Selection Tools

Selection tools help isolate people, objects, backgrounds, and specific regions of an image. Users can refine edges and combine selections with masks or adjustment layers to control exactly where edits appear.

Accurate selections are important for portrait retouching, object removal, background replacement, and combining several photographs into one composition.

### Photo Retouching

Photoshop includes tools for correcting blemishes, removing unwanted objects, adjusting lighting, and refining image details. Healing tools and content aware features can help repair selected areas by blending them with surrounding image content.

Retouching can range from subtle corrections to extensive image reconstruction. Working with separate layers and masks helps retain control over the original photograph.

### Color Correction

Color tools allow users to adjust exposure, contrast, highlights, shadows, saturation, and tonal balance. Adjustment layers can apply these changes while keeping the source image intact.

Curves, color balance, hue and saturation controls, and other adjustments help create consistent results across photographs and graphic compositions.

### Background Removal and Replacement

Selection and masking tools can isolate a subject from its background. Users can then place the subject over a different scene, create a transparent background, or refine the edges around hair and other fine details.

Generative tools can also create a replacement background based on a text description. Results can be reviewed and refined with the standard editing workspace.

## Generative AI and Intelligent Editing

### Generative Fill

Generative Fill can add, remove, or replace content within a selected area using text instructions. It creates editable results that can be reviewed alongside the rest of the composition.

This feature is useful for changing selected objects, extending visual concepts, or making localized edits without manually painting every detail.

### Generative Expand

Generative Expand extends the canvas beyond the original image boundaries and generates additional content that fits the surrounding scene.

It can help adjust an image to a different aspect ratio, create more space around a subject, or extend backgrounds when the original photograph has limited framing.

### Remove Tool

The Remove tool helps erase unwanted objects and distractions from photographs. It analyzes the surrounding image to fill the selected area with matching visual content.

The result depends on the complexity of the background and the objects being removed. Detailed scenes may need further manual refinement.

### Generate Image and Generate Background

Supported generative features can create visual elements or backgrounds from text descriptions. Users can explore variations and then refine the selected result with layers, masks, color adjustments, and other editing tools.

Availability may depend on the active Adobe plan, generative credits, region, and application settings.

## Graphic Design and Digital Art

### Typography and Text Effects

Photoshop includes text tools for adding headings, labels, captions, and decorative typography. Text layers can be repositioned, styled, transformed, and combined with other design elements.

Text can be used in posters, banners, thumbnails, advertisements, and social media graphics. Layer effects and masks help integrate typography into a larger visual composition.

### Brushes and Digital Painting

Brush tools support digital drawing, painting, texture work, and localized image adjustments. Users can configure brush size, softness, opacity, and other settings to suit the task.

Custom brushes and supported brush sets expand the available range of marks and textures, making the application useful for illustration and digital artwork.

### Compositing

Image compositing combines elements from multiple sources into a single scene. Layers, masks, blending modes, transformations, and color adjustments help align the elements and create a coherent result.

This workflow is useful for conceptual artwork, advertising graphics, photo montages, and complex visual scenes.

### Filters and Effects

Filters can soften, sharpen, distort, stylize, or otherwise alter image content. Smart Filters, when used with compatible layers, allow selected effects to remain adjustable.

Effects can be combined with masks and adjustment layers to control their appearance across specific parts of an image.

## File Formats and Export

### Layered Documents

Photoshop uses PSD and PSB formats to retain layers and supported editing information. PSD is commonly used for layered documents, while PSB is designed for very large documents that exceed standard PSD limits.

Keeping an editable source file makes it easier to revisit a design, update text, replace images, or adjust individual effects later.

### Common Image Formats

The application can work with common image formats, including JPEG, PNG, TIFF, GIF, and other supported media types. Format choice depends on whether the image needs transparency, compact file size, print preparation, or retained editing data.

### Export Settings

Export controls help users select image dimensions, file format, quality, and other output settings. These options are useful when preparing images for websites, presentations, printing, or social media publishing.

Reviewing the exported image helps confirm that colors, transparency, dimensions, and compression match the intended use.

## Workspace and Customization

Photoshop provides a configurable workspace with panels for layers, properties, color, brushes, adjustments, and other editing functions. Users can arrange panels and save workspace layouts for different creative tasks.

Keyboard shortcuts, actions, and supported extensions can help reduce repetitive work. The available tools and interface elements may vary according to the active workspace and installed components.
